# Emergency Alert UI Update

The accident alert was redesigned for a stronger critical-emergency presentation.

Changes:
- Dark red/black full-screen emergency modal
- Animated hazard stripe and pulsing red glow
- Large ACCIDENT DETECTED / POSSIBLE ACCIDENT heading
- Large countdown for possible-impact verification
- Compact speed/confidence cards
- Compact DISTRESS / POLICE / HOSPITAL status tiles
- Simplified controls: MUTE SIREN, OPEN GPS, I'M SAFE, CONFIRM EMERGENCY, ACKNOWLEDGE
- Removed long explanatory paragraphs from the emergency popup
- Persistent flashing critical banner on Driver pages
- Reduced-motion accessibility preserved
