Prioritized fixes:

1. **P1 — prevent lost/duplicate offline boarding and GPS actions.** `frontend/src/offlineQueue.js:76-116` snapshots the queue, awaits requests and overwrites storage. In-memory reproduction queued B while A was sending: expected B retained, actual queue length 0. Parallel flushes sent A twice. Concurrent callers exist in `Layout.jsx:544,553` and `LiveLocation.jsx:284`. Serialize per-owner drains, reconcile by item ID, preserve newly added/replaced records and use server idempotency keys.
2. **P1 — retain retryable offline failures.** `offlineQueue.js:103-112` discards every HTTP response failure, including 503/429 and expired-session 401. Reproduced 503: expected queued count 1, actual 0. Classify retryable errors, pause on expired auth and surface permanent failures. Layout ignores the returned failure count.
3. **P2 — neutralize spreadsheet formulas.** `pages/Boarding.jsx` `escapeCsvValue` and `pages/Users.jsx` `downloadCredentials` quote delimiters but do not neutralize formula-prefixed names/IDs/other values. Escape dangerous prefixes before CSV quoting.
4. **P2 — centralize deployment URLs and socket authentication.** `ForgotPassword.jsx` defaults to `http://localhost:4000/api`, while `api.js` uses `/api`; every inspected Socket.IO client defaults to localhost and supplies no JWT. Default production URL behavior is inconsistent; deployment impact depends on supplied Vite variables. Coordinate authenticated server rooms with backend review.
